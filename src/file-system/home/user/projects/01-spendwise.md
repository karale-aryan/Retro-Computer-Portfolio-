



# SpendWise
## 2026

- Java
- Spring Boot
- React
- JWT

SpendWise is a full-stack AI-powered expense management system that helps users track budgets, analyze spending patterns, and receive smart financial predictions in real time. Engineered with secure JWT authentication, role-based access control, and thoroughly unit-tested REST APIs built to handle multiple concurrent users reliably.
