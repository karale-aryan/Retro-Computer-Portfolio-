



# finSight AI
## 2026

- TypeScript
- CI/CD
- GitHub Actions

finSight AI is a live SaaS platform that audits an organization's AI tool subscriptions, identifies redundant or underutilized services, and surfaces actionable cost-saving opportunities. Features a TypeScript-based frontend and a fully automated CI/CD deployment pipeline via GitHub Actions.
