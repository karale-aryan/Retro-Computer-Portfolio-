



# AskMyRepo
## 2026

- Next.js
- Spring Boot
- PostgreSQL
- pgvector
- GitHub OAuth

AskMyRepo is a full-stack AI codebase assistant that lets developers query any GitHub repository using AST-aware semantic search (Tree-sitter) and receive answers grounded in source code with verifiable line-level citations. Built with Next.js 15, Java 21 / Spring Boot 3, PostgreSQL + pgvector, and secure GitHub OAuth2 integration.
