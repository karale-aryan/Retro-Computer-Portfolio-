



# KrishiMitra-Ai
## 2026

- Spring Boot
- TypeScript
- React
- Python
- PostgreSQL

KrishiMitra AI is an intelligent agricultural platform designed to empower farmers with AI-driven crop guidance, weather-aware recommendations, and actionable farming insights. Built with a Java Spring Boot backend, TypeScript + React frontend, and a Python-based AI layer — fully Dockerized for scalable deployment.
